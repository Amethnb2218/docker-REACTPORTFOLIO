# sndak11_groupe-5_sonarqube

Ce dossier contient les livrables du groupe 5 pour le module SonarQube.

## Contenu

1. `01_document_synthese_sonarqube_groupe5.docx` : document detaille de synthese (avec captures d'ecran integrees).
2. `02_cheatsheet_sonarqube_groupe5.docx` : fiche concise des commandes et concepts.
3. `03_video_demo_sonarqube_groupe5.mp4` : video de demo (~10 min) montrant toutes les etapes pratiques.
4. `04_description_textuelle_demo_sonarqube_groupe5.docx` : description textuelle de la demo (avec 18 captures d'ecran integrees).
5. `05_diapositives_presentation_sonarqube_100_slides.pptx` : diapositives de presentation (100 slides).
6. `05_annexe_concepts_definition_syntaxe_exemple.pptx` : annexe avec definition, syntaxe et exemple par concept.
7. `captures/` : dossier contenant les 20 captures d'ecran de la demo.
8. `sources_officielles.md` : sources Internet officielles utilisees.

Les versions Markdown (.md) des documents sont aussi fournies pour lecture rapide.
