# 5.6 Installation

## Options d'installation locale

### Option 1 : Minikube (Recommande pour l'apprentissage)

```bash
# Windows (avec Chocolatey)
choco install minikube

# ou avec winget
winget install Kubernetes.minikube

# Demarrer le cluster
minikube start --driver=docker --memory=4096 --cpus=2

# Verifier
minikube status
kubectl cluster-info
```

### Option 2 : Docker Desktop (Plus simple sur Windows/Mac)

1. Ouvrir Docker Desktop
2. Settings → Kubernetes
3. Cocher "Enable Kubernetes"
4. Cliquer "Apply & Restart"
5. Attendre que le statut soit vert

```bash
# Verifier
kubectl cluster-info
kubectl get nodes
```

### Option 3 : Kind (Kubernetes in Docker)

```bash
# Installation
go install sigs.k8s.io/kind@latest
# ou
choco install kind

# Creer un cluster
kind create cluster --name portfolio

# Verifier
kubectl cluster-info --context kind-portfolio
```

## Installation de kubectl

```bash
# Windows (Chocolatey)
choco install kubernetes-cli

# Windows (winget)
winget install Kubernetes.kubectl

# Verifier l'installation
kubectl version --client
```

## Installation de l'Ingress Controller (nginx)

### Avec Minikube
```bash
minikube addons enable ingress
```

### Avec Docker Desktop / Kind
```bash
kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.10.0/deploy/static/provider/cloud/deploy.yaml

# Attendre que le controller soit pret
kubectl wait --namespace ingress-nginx \
  --for=condition=ready pod \
  --selector=app.kubernetes.io/component=controller \
  --timeout=120s
```

## Deploiement de notre projet

### Prerequis
1. Kubernetes actif (Minikube ou Docker Desktop)
2. kubectl configure
3. Ingress Controller installe
4. Images Docker buildees localement

### Etape 1 : Build des images Docker

```bash
# Depuis la racine du projet REACTPORTFOLIO
docker build -t portfolio-frontend ./reactportfolio
docker build -t portfolio-backend "./EXPRESSJS PORTFOLIO"
```

### Avec Minikube : charger les images dans le cluster
```bash
minikube image load portfolio-frontend:latest
minikube image load portfolio-backend:latest
```

### Etape 2 : Deployer avec le script

```bash
cd kubernetes
chmod +x deploy.sh
./deploy.sh up
```

### Etape 3 : Configurer /etc/hosts

```bash
# Ajouter dans C:\Windows\System32\drivers\etc\hosts (en admin)
127.0.0.1 portfolio.local
```

### Avec Minikube :
```bash
# Obtenir l'IP de Minikube
minikube ip
# Ajouter : <minikube-ip> portfolio.local
```

### Etape 4 : Acceder a l'application

```
http://portfolio.local        → Frontend React
http://portfolio.local/api    → Backend Express
```

## Verification de l'installation

```bash
# Voir tous les pods
kubectl get pods -n portfolio

# Voir les services
kubectl get svc -n portfolio

# Voir l'ingress
kubectl get ingress -n portfolio

# Logs d'un pod
kubectl logs -f deployment/backend -n portfolio

# Entrer dans un pod
kubectl exec -it deployment/backend -n portfolio -- sh
```

## Desinstallation

```bash
./deploy.sh down

# ou manuellement
kubectl delete namespace portfolio
kubectl delete pv mongo-pv
```
