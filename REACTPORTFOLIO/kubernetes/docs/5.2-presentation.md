# 5.2 Presentation - Quoi ?

## Definition

**Kubernetes** (K8s) est une plateforme open-source d'orchestration de conteneurs, developpee par Google puis donnee a la CNCF (Cloud Native Computing Foundation) en 2014.

Il automatise le deploiement, la mise a l'echelle et la gestion d'applications conteneurisees.

## Origine

- Cree par Google, base sur 15 ans d'experience avec **Borg** (systeme interne)
- Open-source depuis 2014
- Maintenu par la CNCF depuis 2015
- Version stable actuelle : 1.30+ (2024)

## Fonctionnalites principales

### Orchestration de conteneurs
- Placement intelligent des conteneurs sur les noeuds
- Gestion du cycle de vie complet

### Self-healing
- Redemarrage automatique des conteneurs en echec
- Remplacement des noeuds defaillants
- Suppression des conteneurs ne repondant plus aux health checks

### Scaling automatique
- Horizontal Pod Autoscaler (HPA) : ajuste le nombre de pods
- Vertical Pod Autoscaler (VPA) : ajuste les ressources
- Cluster Autoscaler : ajuste le nombre de noeuds

### Service Discovery et Load Balancing
- DNS interne automatique
- Repartition de charge entre les pods
- Exposition des services en interne/externe

### Rolling Updates et Rollbacks
- Deploiements progressifs sans interruption
- Retour a une version precedente en une commande

## Ecosysteme

- **Helm** : gestionnaire de packages K8s
- **Istio** : service mesh
- **Prometheus/Grafana** : monitoring
- **ArgoCD** : GitOps / deploiement continu
- **Cert-Manager** : gestion TLS automatique

## Kubernetes vs Docker Compose

| Aspect | Docker Compose | Kubernetes |
|--------|---------------|------------|
| Scope | Une seule machine | Cluster multi-noeuds |
| Scaling | Manuel | Automatique (HPA) |
| Haute dispo | Non | Oui (ReplicaSets) |
| Reseau | Bridge simple | SDN complet |
| Production | Dev/Test | Production-ready |
| Complexite | Simple | Plus complexe |
