# 4.5. Installation de SonarQube

## Prérequis

- Docker et Docker Compose installés
- Au moins 4 Go de RAM disponibles
- Jenkins opérationnel (voir pipeline existant)

## 1. Docker Compose pour SonarQube

Créer le fichier `docker-compose.sonarqube.yml` :

```yaml
services:
  sonarqube:
    image: sonarqube:community
    container_name: sonarqube
    depends_on:
      - sonarqube-db
    ports:
      - "9000:9000"
    environment:
      - SONAR_JDBC_URL=jdbc:postgresql://sonarqube-db:5432/sonarqube
      - SONAR_JDBC_USERNAME=sonar
      - SONAR_JDBC_PASSWORD=sonar
    volumes:
      - sonarqube_data:/opt/sonarqube/data
      - sonarqube_extensions:/opt/sonarqube/extensions
      - sonarqube_logs:/opt/sonarqube/logs
    networks:
      - sonarqube-net

  sonarqube-db:
    image: postgres:15
    container_name: sonarqube-db
    environment:
      - POSTGRES_USER=sonar
      - POSTGRES_PASSWORD=sonar
      - POSTGRES_DB=sonarqube
    volumes:
      - postgresql_data:/var/lib/postgresql/data
    networks:
      - sonarqube-net

volumes:
  sonarqube_data:
  sonarqube_extensions:
  sonarqube_logs:
  postgresql_data:

networks:
  sonarqube-net:
```

## 2. Lancer SonarQube

```bash
docker compose -f docker-compose.sonarqube.yml up -d
```

Accéder à l'interface : **http://localhost:9000**
- Login par défaut : `admin` / `admin`
- Changer le mot de passe au premier accès

## 3. Configuration du projet dans SonarQube

1. Créer un nouveau projet : `portfolio-react-express`
2. Générer un token d'authentification
3. Choisir la méthode d'analyse : "With Jenkins"

## 4. Fichier sonar-project.properties

Créer à la racine du projet :

```properties
sonar.projectKey=portfolio-react-express
sonar.projectName=Portfolio React Express
sonar.projectVersion=1.0

# Sources
sonar.sources=reactportfolio/src,EXPRESSJS PORTFOLIO/src
sonar.tests=EXPRESSJS PORTFOLIO/src

# Exclusions
sonar.exclusions=**/node_modules/**,**/dist/**,**/build/**

# Encodage
sonar.sourceEncoding=UTF-8

# JavaScript/TypeScript
sonar.javascript.lcov.reportPaths=coverage/lcov.info
```

## 5. Intégration dans Jenkins

Ajouter dans le `Jenkinsfile` une étape SonarQube :

```groovy
stage('SonarQube Analysis') {
    steps {
        withSonarQubeEnv('SonarQube') {
            sh '''
                sonar-scanner \
                  -Dsonar.projectKey=portfolio-react-express \
                  -Dsonar.sources=. \
                  -Dsonar.host.url=http://sonarqube:9000 \
                  -Dsonar.token=$SONAR_TOKEN
            '''
        }
    }
}

stage('Quality Gate') {
    steps {
        timeout(time: 5, unit: 'MINUTES') {
            waitForQualityGate abortPipeline: true
        }
    }
}
```

## 6. Plugin Jenkins

Dans Jenkins (Manage Jenkins > Plugins) :
- Installer **SonarQube Scanner for Jenkins**
- Configurer le serveur SonarQube dans Manage Jenkins > System
